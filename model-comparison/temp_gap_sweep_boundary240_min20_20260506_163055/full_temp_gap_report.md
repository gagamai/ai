# 240 度分界线跨温度域外推实验报告

## 实验设置

- 目标频率：FREQ1。
- 数据映射：`X=data(:,1:4)`，`T=data(:,5)`，`FREQ1=data(:,6)`。
- 高低温分界线：`boundaryTemp = 240`。
- 低温训练域：`T <= 240`，样本 `1-50`。
- 强制训练样本：样本 `50`，温度 `239.88674`，用于固定每次训练集最大温度。
- 训练样本数：`N=20` 和 `N=30`。
- 每点重复次数：`20`。
- 高温测试集：每个 gap band 固定 8 个样本。
- 正式指标：`Clean_HighTest_MAPE_Mean`。
- 灾难性剔除阈值：`HighTest_MAPE >= 100%`。本轮所有点 `KeptRunRate = 100%`，没有灾难性重复被剔除。

## 主要结论

- RD-GEP 在所有温度间隔下都是误差最低的模型。
- RD-GEP 在 2% 阈值下可跨越到约 `40.13208 度`，在 5% 阈值下可跨越到约 `50.40487 度`，在 10% 阈值下可跨越到约 `62.08186 度`。
- 当跨域间隔增大到约 `80.32735 度` 时，RD-GEP 误差升至约 `14.62%-16.35%`，说明这一距离已经进入明显外推失稳区。
- BaseGEP、Kriging、SVR-RBF 都随跨域间隔增大呈现清晰误差上升；MLP 在远距离区间误差最高且波动较大。
- N=30 相比 N=20 在近距离 gap 下通常更好，但在最远 gap 下 RD-GEP 的 N=30 略差于 N=20，说明极远外推不一定只靠增加低温样本就能改善。
